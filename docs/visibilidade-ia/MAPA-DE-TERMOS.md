# Fase 1: mapa de termos do pilar de IA

Data: 28/10/2026. Fonte: autocompletar do Google (`hl=pt-BR`, `gl=br`), consultado nesta data.
Sem Planejador de Palavras-chave, então **não há volume**: "aparece no autocompletar" quer dizer só
que a busca existe no Brasil em quantidade suficiente para o Google sugerir. Volume: **a confirmar**.

Legenda: **Sugere?** = o Google sugere a busca ou variações dela · **Existe hoje** = já há página no site.

## O que os dados mudaram no plano

1. **"visibilidade em IA" não tem sugestão nenhuma. "SEO para IA" tem várias** ("seo para ia
   generativa", "seo para ia como chama", "seo para ia curso"). Recomendação: URL do pilar
   **`/seo-para-ia/`** em vez de `/visibilidade-em-ia/`. "Visibilidade em IA" continua no texto.
2. **"como aparecer no gemini"** é ambígua: as sugestões são "como aparecer o gemini" e "como faz
   para aparecer o gemini no celular" (gente querendo ativar o app). Uma página com esse nome
   atrairia o público errado. Recomendação: trocar o satélite do Gemini por **"respostas de IA do
   Google"** (AI Overviews + Gemini juntos), que tem sugestão ("ai overviews do google").
3. **Perplexity: nenhuma sugestão.** Página própria seria fina (pouco conteúdo para pouca busca).
   Recomendação: virar seção dentro do pilar.
4. **Goiânia: nenhuma sugestão** para "seo para ia goiânia" ou "geo goiânia" (esta última é o nome
   de outra empresa, a Geo 360). Página local sem procura é exatamente o que o prompt chama de
   doorway. Recomendação: **não criar a página de Goiânia agora**; o pilar ganha um bloco
   "atendimento presencial em Goiânia e online no Brasil", como as outras páginas nacionais.
5. **"consultoria geo", "agência geo", "especialista em geo"** puxam geotecnia, geologia,
   geoprocessamento. "GEO" sozinho não é termo comercial em português. O lado comercial vai por
   "SEO para IA" e pelo pedido concreto: "como fazer minha empresa aparecer no ChatGPT".
6. **Descoberta que vale ouro:** "como **cadastrar** minha empresa no chatgpt" e "como **colocar**
   minha empresa no chatgpt". O dono acha que existe um cadastro, como no Google Meu Negócio. Não
   existe. Responder isso de forma direta é o melhor gancho do pilar.
