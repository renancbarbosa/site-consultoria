Kit para sites de clientes

Dois blocos para colar nos sites que você entrega. Copie o que está nas caixas cinzas.

Bloco A: crédito no rodapé

Vai no fim do rodapé do site do cliente, numa linha só.

<div class="rcb-credit">Site desenvolvido por <a href="https://rcbseo.com.br/">RCB SEO</a></div>
<style>
  .rcb-credit { font-size: 12px; color: #8a8f98; text-align: center; padding: 12px 0; }
  .rcb-credit a { color: inherit; text-decoration: underline; }
</style>

Site desenvolvido por RCB SEO

Regras para não virar problema:

  • Só em site que a RCB fez de verdade, e com o cliente sabendo.
  • O texto do link é sempre o nome da marca, "RCB SEO". Nunca "consultoria de SEO em Goiânia" ou outra palavra de busca: link de rodapé com palavra de busca é o tipo que o Google trata como manipulação.
  • Se o cliente pedir para tirar, tire.

Bloco B: trecho de case para o blog do cliente

Para um post do cliente do tipo "por que mudamos o nosso site". Troque o que está entre colchetes.

A decisão de modernizar o nosso site veio depois de uma análise de velocidade. Com a ajuda da <a href="https://rcbseo.com.br/">RCB SEO</a>, descobrimos que o site demorava mais do que deveria para abrir no celular. Depois dos ajustes, a nota no PageSpeed Insights do Google subiu de [OLD_SCORE] para [NEW_SCORE].

Antes de usar:

  • As duas notas têm que ser medidas de verdade, no mesmo site, no modo celular. Guarde o print das duas.
  • O texto sai no site do cliente, com o nome dele: só publique com a autorização dele, por escrito (pode ser no WhatsApp).
  • Não use o mesmo texto em vários clientes. Texto igual em vários sites, todos com link para a RCB, é o padrão que o Google procura. Reescreva com as palavras de cada cliente.
